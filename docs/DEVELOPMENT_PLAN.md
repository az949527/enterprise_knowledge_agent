## 一、产品定位与验收边界

最终定位：

  轻量、桌面优先、可评估、结构感知、多格式、证据可追溯的企业知识工作台。

当前产品验收顺序：

  1. Windows 桌面 EXE。
  2. 桌面本地索引和 BM25 查询。
  3. 可选远程 LLM、Embedding 和 Reranker。
  4. Web 代码只保留公共能力复用，不继续扩展浏览器产品界面。

当前桌面主调用链：

  app/desktop/main.py
    -> app/documents/parsers.py
    -> app/lite/indexer.py
    -> app/lite/desktop_query.py
    -> app/lite/bm25_search.py
    -> app/lite/remote_retrieval.py（可选）
    -> app/lite/generator.py

默认策略：

  BM25 + 可选 LLM。
  Embedding 和 Reranker 默认关闭。
  不默认同时启用 Embedding、Reranker 和 LLM。

本清单中的“完成”必须同时满足：

  1. 代码实现存在。
  2. 对应测试或固定用例存在。
  3. 桌面主路径实际接入。
  4. 关键指标没有超过回归门槛。
  5. 文档明确记录已完成项和未完成边界。

状态定义：

- [ ] 未开始
- [~] 已有第一版实现，尚未达到阶段验收
- [x] 已通过阶段验收
- [D] 明确延期，不作为当前阶段阻塞项

验收原则：

  1. 峰值内存主要受单页、单 Sheet 批次和 Embedding 批次影响。

  3. 索引完成后节点、临时对象和页面图片能够释放。
  4. 索引失败或取消后内存能够回落。
  5. 旧索引仍然可用，或界面明确提示需要重建。

## 十七、最终判断标准
